Le projet

La marelle (ou jeu du moulin) est un jeu de stratégie à deux joueurs sur un plateau de 24 cases. Nous l'avons programmée en Python : la logique du jeu est une classe indépendante de l'affichage, et l'interface est réalisée avec pygame.

Les règles

  1. Pose : chaque joueur place à tour de rôle ses 9 pions sur une case libre.
  2. Déplacement : ensuite, on déplace un pion vers une case voisine libre le long des lignes.
  3. Moulin : aligner 3 pions permet de retirer un pion adverse. Un pion déjà en moulin est protégé, sauf si tous les pions adverses sont en moulin.
  4. Saut : avec seulement 3 pions, on peut sauter sur n'importe quelle case libre.
  5. Victoire : l'adversaire n'a plus que 2 pions, ou ne peut plus bouger.

Aspects techniques

  • Logique du jeu : structure_marelle.py (classe Marelle)
  • Déplacement utilisant un graphe et une liste
  • Interface : pygame, exportée pour le navigateur avec pygbag (WebAssembly)
  • Plateaux : plusieurs plateaux de jeux à thèmes disponibles
  • Hébergement : GitHub Pages
